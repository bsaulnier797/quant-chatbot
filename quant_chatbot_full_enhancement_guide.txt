1.1 INTERACTIVE FINANCE LESSONS TAB
--------------------------------------------------------------------------------

WHAT IT IS:
  A dedicated "Learn Finance" tab in Streamlit alongside the chatbot tab.
  Contains structured lessons that use your live data tools to make every
  concept tangible with real market data.

HOW TO BUILD IT:
  In app.py, add tabs using st.tabs():

    tab1, tab2 = st.tabs(["💬 Chatbot", "📚 Learn Finance"])

  Inside the Learn Finance tab, build these lessons using st.expander()
  for each one so the page stays clean:

  LESSON 1 — What is a Stock Return?
    - Plain English explanation: "A return is simply how much money you
      made or lost as a percentage of what you invested"
    - Show the formula: Return = (End Price - Start Price) / Start Price
    - Live example: fetch AAPL data and show the actual numbers plugged in
    - Let the user pick any ticker and see the calculation live
    - End with: "A 10% return means if you invested $1,000 you now have $1,100"

  LESSON 2 — What is Volatility?
    - Analogy: "Think of volatility like turbulence on a flight. A smooth
      flight vs a bumpy one — both get you there, but the experience is
      very different"
    - Show two contrasting stocks on one chart:
      * Stable: KO (Coca-Cola) or JNJ (Johnson & Johnson)
      * Volatile: TSLA or NVDA
    - Show their rolling volatility charts side by side
    - Let the user pick two stocks to compare volatility themselves

  LESSON 3 — What is the Sharpe Ratio?
    - Analogy: "Two runners finish a race in the same time, but one barely
      broke a sweat and the other was exhausted. The Sharpe ratio is like
      measuring how efficiently you ran the race"
    - Show two stocks: one with high return but low Sharpe, one with
      moderate return but high Sharpe
    - Explain why the high-Sharpe stock is actually the better investment
      on a risk-adjusted basis
    - Interactive: let user input any ticker and see its Sharpe ratio
      with a plain English interpretation ("above 1.0 is good, above 2.0
      is excellent, below 0 means you'd have been better off in cash")

  LESSON 4 — What is Max Drawdown?
    - Analogy: "Imagine your portfolio is a hiker. Max drawdown is the
      deepest valley they fell into before climbing back up"
    - Show a chart with the peak and trough highlighted visually
    - Explain the psychological impact — "a 50% drawdown requires a 100%
      gain just to break even"
    - Compare a low-drawdown stock (SPY) vs high-drawdown stock (individual)

  LESSON 5 — What is Beta?
    - Analogy: "Beta is like a volume knob. A beta of 2.0 means when the
      market turns up the volume by 1, this stock turns it up by 2"
    - Show SPY (beta=1.0), KO (beta~0.6), NVDA (beta~1.7) on one chart
    - Let user pick a stock and see its beta vs the market
    - Explain: "High beta = higher risk AND higher potential reward"

  LESSON 6 — What is Diversification?
    - Analogy: "Don't put all your eggs in one basket"
    - Show correlation matrix between stocks in different sectors
    - Demonstrate: a portfolio of AAPL + MSFT + GOOGL vs
      AAPL + MSFT + GLD (gold) — show how adding uncorrelated assets
      reduces overall portfolio volatility
    - Interactive: let user build a mini portfolio and see the effect

ESTIMATED TIME: 1-2 weeks
IMPACT: Very high — no other student project has this

1.2 CONCEPT EXPLAINER TOOL
--------------------------------------------------------------------------------

WHAT IT IS:
  A new LangChain tool that triggers whenever the user asks "what is X"
  or "explain X" for any finance term. Claude explains it in plain English
  appropriate to the current mode.

HOW TO BUILD IT:
  Add to agent/tools.py:

  @tool
  def explain_concept_tool(input: str) -> str:
      """
      Use this tool when the user asks what a financial term or concept means.
      Triggers on: "what is", "explain", "define", "what does X mean",
      "I don't understand X", "tell me about X"
      Input: the term or concept to explain (e.g. "Sharpe ratio", "beta",
      "P/E ratio", "market cap", "dividend", "volatility")
      """
      return f"User wants a plain English explanation of: {input}"

  The tool signals to Claude that an explanation is needed. Claude then
  generates the explanation based on the system prompt for the current mode.

  In Learning Mode the explanation will:
    - Use a real world analogy
    - Show the formula with words, not symbols
    - Give a concrete example with real numbers
    - End with why it matters to an investor

  In Expert Mode the explanation will:
    - Give the precise definition
    - Show the mathematical formula
    - Note edge cases or limitations
    - Reference how it is used in practice

ESTIMATED TIME: 1 day
IMPACT: Makes the chatbot genuinely educational

            How much you made or lost as a percentage.
            Formula: (End Price - Start Price) / Start Price
            
            **Volatility**
            How much a stock's price swings up and down.
            Higher = riskier. Measured as annualized standard deviation.
            
            **Sharpe Ratio**
            Return per unit of risk. Above 1.0 is good, above 2.0 is excellent.

            How much a stock moves relative to the market.
            Beta > 1 = more volatile than market. Beta < 1 = less volatile.
            
            **P/E Ratio**
            Price divided by earnings per share. How much investors pay
            for each dollar of profit.
            """)

2.1 PORTFOLIO ANALYZER
--------------------------------------------------------------------------------

WHAT IT IS:
  Takes multiple tickers and weights, analyzes them as a portfolio, and
  computes portfolio-level metrics including volatility, Sharpe, and
  correlation between holdings.

KEY METRICS TO COMPUTE:
  - Weighted portfolio return
  - Portfolio volatility using covariance matrix:
    Formula: sqrt(weights^T * cov_matrix * weights) * sqrt(252)
  - Portfolio Sharpe ratio
  - Correlation matrix between all holdings
  - Individual contribution of each ticker to overall return

HOW TO USE IT:
  User input format: "Analyze a portfolio of 50% AAPL, 30% MSFT, 20% GOOGL"
  The tool parses tickers and weights, fetches data, and returns full analysis

IN LEARNING MODE:
  Explain what each portfolio metric means and why diversification matters.
  Show visually how adding an uncorrelated asset reduces overall risk.

ESTIMATED TIME: 3-5 days
IMPACT: Very high for quant finance interviews

--------------------------------------------------------------------------------
2.2 ADDITIONAL QUANT METRICS
--------------------------------------------------------------------------------

ADD THESE TO data/stock_data.py:

  Beta vs S&P 500
    Formula: cov(stock_returns, spy_returns) / var(spy_returns)
    Use SPY as benchmark. Fetch both simultaneously.

  Jensen's Alpha
    Formula: stock_return - (risk_free + beta * (market_return - risk_free))
    Positive alpha = outperformed on risk-adjusted basis

  Sortino Ratio
    Formula: (mean_return - risk_free) / downside_std * sqrt(252)
    Only penalizes downside volatility unlike Sharpe which penalizes all

  Calmar Ratio
    Formula: annualized_return / abs(max_drawdown)
    Return per unit of drawdown risk

  Value at Risk (VaR) at 95% confidence
    Formula: np.percentile(daily_returns, 5)
    "There is a 5% chance of losing more than X% in a single day"

IN LEARNING MODE:
  Each metric gets a plain English explanation and analogy before the number.

ESTIMATED TIME: 2-3 days
IMPACT: Very high — these are exactly what quant interviewers ask about

3.1 CANDLESTICK CHARTS WITH VOLUME
--------------------------------------------------------------------------------

WHAT IT IS:
  Replace the simple line chart with a professional candlestick chart
  that shows Open, High, Low, Close, and Volume for each day.

HOW TO BUILD IT:
  In charts/plotting.py:

  def plot_candlestick(ticker, period):
      from plotly.subplots import make_subplots
      df = get_price_history(ticker, period)
      
      fig = make_subplots(rows=2, cols=1, shared_xaxes=True,
                          row_heights=[0.7, 0.3])
      
      fig.add_trace(go.Candlestick(
          x=df.index,
          open=df["Open"],
          high=df["High"],
          low=df["Low"],
          close=df["Close"],
          name=ticker
      ), row=1, col=1)
      
      fig.add_trace(go.Bar(
          x=df.index,
          y=df["Volume"],
          name="Volume",
          marker_color="lightblue"
      ), row=2, col=1)
      
      return fig

IN LEARNING MODE:
  Add an explanation of what candlestick charts show and how to read them.
  Green candle = price went up that day. Red candle = price went down.

4.2 CONVERSATIONAL MEMORY
--------------------------------------------------------------------------------

WHAT IT IS:
  The bot currently treats every question independently. With memory, it
  remembers earlier parts of the conversation for natural follow-ups.

HOW TO BUILD IT:
  Pass conversation history into ask() from app.py:

  def ask(client, question, mode, history=[]):
      # Format history as Anthropic messages
      messages = []
      for msg in history[-6:]:  # last 6 messages
          if msg["role"] in ["user", "assistant"]:
              messages.append({
                  "role": msg["role"],
                  "content": msg["content"]
              })
      messages.append({"role": "user", "content": question})
      # rest of function...

  In app.py pass the history:
    response = ask(st.session_state.agent, prompt, mode.lower(),
                   history=st.session_state.messages)

ESTIMATED TIME: 1-2 days
IMPACT: Makes the biggest UX difference of any feature
